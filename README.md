# DiaryApp

기록보다 **회고**에 무게를 둔 1인용 개인 일기장 웹앱입니다. 매일 부담 없이 짧게 기록하고, 시간이 지난 뒤 "7일 전", "1개월 전", "N년 전" 오늘의 기록을 자동으로 다시 만나는 경험을 핵심 가치로 설계했습니다.

## 주요 기능

- **회고 홈 화면**: 오늘 날짜를 기준으로 7일 전 / 1개월 전 / N년 전 기록을 계단식으로 보여줍니다. 기록이 없는 시간 단위는 자연스럽게 생략되어, 기록이 쌓이기 전인 초기 사용 단계에서도 회고 기능이 바로 의미 있게 동작합니다.
- **새 일기 작성**: 날짜(기본값 오늘) · 본문 · 태그(다중) · 기분(5단계, 선택) · 이미지 첨부(다중, 선택)를 입력할 수 있습니다.
- **타임라인**: 최신순으로 전체 기록을 목록으로 확인합니다.
- **검색**: 본문 텍스트 검색과 태그 필터(OR 조건)를 지원합니다.
- **이미지 첨부**: jpg/jpeg/png/gif/webp 형식, 장당 5MB 이하로 제한하여 서버에서 검증 후 로컬 파일시스템에 저장합니다.

## 기술 스택

- **프레임워크**: C# / Blazor Server (ASP.NET Core, .NET 10)
- **데이터베이스**: SQLite (단일 파일, EF Core로 접근)
- **이미지 저장**: 로컬 파일시스템 (`wwwroot/uploads/`), 경로만 DB에 기록
- **테스트**: xUnit

## 프로젝트 구조

```
src/DiaryApp/
├── Components/       # Blazor 페이지 및 레이아웃 (홈, 새 글 작성, 타임라인)
├── Data/              # EF Core DbContext
├── Models/            # DiaryEntry, Tag, DiaryImage
└── Services/          # 회고/검색/이미지 저장 도메인 서비스
tests/DiaryApp.Tests/   # 서비스 단위 테스트
```

## 실행 방법

```bash
dotnet run --project src/DiaryApp
```

기본적으로 `http://localhost:5126` (HTTPS 프로필은 `https://localhost:7075`)에서 접속할 수 있습니다.

## 테스트

```bash
dotnet test
```

회고 로직(월 경계, 윤년 등 엣지 케이스), 검색/태그 필터, 이미지 업로드 검증에 대한 단위 테스트가 포함되어 있습니다.

## 범위 밖
